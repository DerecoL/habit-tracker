# 生活习惯打卡系统

用于每日对固定习惯项进行打卡，并查看周/月/年进度与趋势曲线。

## 功能

- **习惯管理**：添加、编辑、删除固定习惯项，支持自定义名称和颜色
- **今日打卡**：每天对每个习惯点击即可标记完成/未完成
- **总览**：一眼查看今日、本周、本月、本年的完成进度条（完成数/总数、百分比）
- **周/月/年进度**：在「今日打卡」页中查看每个习惯在本周、本月、本年的完成条
- **趋势曲线**：最近 30 天每日完成率折线图，便于观察整体趋势

## 使用

```bash
# 安装依赖
npm install

# 开发
npm run dev

# 构建
npm run build

# 预览构建结果
npm run preview
```

数据保存在浏览器本地（localStorage），无需后端。

## 在手机上使用

本应用已做移动端适配，支持小屏与触控，并可在手机浏览器中「添加到主屏幕」当 App 使用。

**方式一：部署到网上后访问**

- 将项目构建后部署到任意静态托管（如 Vercel、Netlify、GitHub Pages 等），得到访问地址
- 用手机浏览器打开该地址即可使用；在浏览器菜单里选择「添加到主屏幕」可像 App 一样使用

**方式二：同一 WiFi 下用电脑 IP 访问**

- 在电脑上运行 `npm run dev` 启动开发服务
- 确保手机和电脑在同一 WiFi 下，在手机浏览器地址栏输入：`http://你的电脑IP:5173`（如 `http://192.168.1.100:5173`）
- 电脑 IP 可在终端执行 `ipconfig`（Windows）或 `ifconfig`（Mac/Linux）查看

**单页版（不依赖 npm）**

- 直接双击打开 `standalone/index.html` 在电脑浏览器中使用
- 若需在手机上用单页版，需通过上述方式二在同一局域网用电脑起一个简单 HTTP 服务（例如在 `standalone` 目录执行 `npx serve -p 3000`），手机访问 `http://电脑IP:3000` 即可
